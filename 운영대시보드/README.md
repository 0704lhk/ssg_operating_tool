# 매출 비교 실습 앱 · 1단계

교육용 가상 매출을 브라우저에서 비교합니다. 실행 위치는 이 폴더입니다.

```sh
npm install
npm run build
npm start
```

내장 Browser에서 http://127.0.0.1:4173 을 엽니다. 서버는 로컬 컴퓨터에서만 접속할 수 있습니다.

빌드는 상위 `A_매출비교/`의 정상 실적 3개와 `04_보고양식.xlsx`만 `dist/data/`에 복사합니다. 원본은 수정하지 않습니다. 이전 빌드는 `../results/build-backups/`에 보존합니다. 원본 A~E는 Git 제외 대상이므로 새 체크아웃에서도 로컬에 실습 자료를 별도로 준비해야 빌드할 수 있습니다.

점포·채널·기간·브랜드·장르 조건을 지표, 점포 비교, 상세 표, 보고서에 함께 적용합니다. 메모는 `record_id`에 연결해 이 Browser의 로컬 저장소에 저장하고 보고서에 포함합니다. 기기 간 또는 팀 공유 기능은 없습니다.

보고서 버튼은 현재 조건의 전체 행을 새로운 Excel 파일로 다운로드합니다. 페이지 이동은 내보내기 범위를 바꾸지 않습니다. 다운로드 저장 위치는 Browser 설정을 따릅니다. 원본 재업로드와 ID가 겹치는 자료는 파일 전체를 거부하고 기존 정상 자료를 보존합니다.

검사 실행:

```sh
npm run verify
```

검사 결과와 검사에서 저장한 보고서는 상위 `results/`에 생성됩니다. Verifier는 최초 원본 해시와 비교하므로 최초 스냅샷이 필요합니다.

행사 준비와 날씨 탭은 2단계 안내만 제공합니다. 실제 자료·API 키는 입력/번들/보고서에 넣지 않습니다. GitHub 작업 대상은 `https://github.com/Lilcob/ssg_operating_tool`이며 커밋/푸시는 사용자의 요청 시 실행합니다.
